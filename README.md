# 🍕 Pizza Sales Analysis

## 📌 Project Overview

The **Pizza Sales Analysis** project focuses on analyzing pizza sales data to identify sales trends, understand customer preferences, and evaluate business performance. The objective is to extract meaningful insights from sales data and support data-driven business decisions using data analytics tools.

## 🎯 Objectives

* Analyze overall sales performance and revenue.
* Identify the best-selling and least-selling pizzas.
* Understand sales trends by day, month, and time.
* Analyze customer ordering patterns and pizza category performance.
* Generate actionable insights to improve business performance.

## 📂 Dataset

The dataset contains pizza sales transaction records, including information such as:

* Order ID and order date
* Pizza name and category
* Pizza size and quantity
* Unit price and total sales


## 🛠️ Tools & Technologies

* **SQL:** Querying sales data and calculating key performance indicators (KPIs).
* **PostgreSQL:** Storing and analyzing structured sales data using SQL queries.
* **Power BI:** Creating interactive dashboards and visualizing sales performance.
* **Excel:** Initial data inspection and validation.
* **Tableau:** Initial data inspection and validation.

## 🔍 Project Workflow

1. **Data Collection:** Loaded the pizza sales dataset.
2. **Data Cleaning:** Checked for missing values, duplicates, and data inconsistencies.
3. **SQL Analysis:** Used SQL queries to calculate KPIs and answer business questions.
4. **Data Visualization:** Built an interactive Power BI dashboard and tableau dashboard to present important metrics and trends.
5. **Insights & Recommendations:** Summarized key findings to support business decisions.

## 📊 Key Performance Indicators (KPIs)

* Total Revenue
* Total Orders
* Total Pizzas Sold
* Average Order Value
* Average Pizzas Per Order

## 📈 Dashboard

The Tableau and Power BI dashboard presents key sales metrics and visualizations, including:

* Daily and monthly sales trends
* Sales performance by pizza category and size
* Best-selling and least-selling pizzas
* Revenue and order distribution
* Comparison of pizza sales performance


## 💡 Key Insights

The analysis aims to identify:

* Peak sales days and months.
* Top-performing pizza categories and sizes.
* Best-selling and least-selling pizza products.
* Revenue trends and customer ordering patterns.
